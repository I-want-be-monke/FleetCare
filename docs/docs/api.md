HTTP-код	Значение
200	Запрос выполнен
201	Запись создана
400	Некорректные данные
404	Автомобиль или заявка не найдены
409	Повторное событие или недопустимый переход статуса
500	Непредвиденная ошибка сервера

пример
Problem Details:
{
"type": "about:blank",
"title": "Событие уже существует",
"status": 409,
"detail": "Показание с таким eventId уже принято."
}
